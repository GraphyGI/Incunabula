01 — Fundación de Marca

El Concepto

Todo sistema visual parte de una idea. La de Incunabula es una de las más ricas de la historia cultural: los primeros libros impresos, la primera vez que el conocimiento fue accesible para todos.

La palabra fundacional

Incunabulum ("cuna" o "origen"). Así como Gutenberg democratizó el conocimiento impreso, nosotros democratizamos el acceso al libro físico, entregándolo a manos que desean leer.

El eterno retorno

Un libro usado no es viejo, es un libro con experiencia. En Incunabula actuamos como esa segunda imprenta que le otorga una nueva vida dentro de una nueva biblioteca personal.

La doble tensión

La marca habita el equilibrio perfecto entre el peso cultural (el aura intocable de lo clásico) y el acceso universal, ofreciendo joyas editoriales con envíos rápidos y precios justos.

El catálogo orgánico

No somos una bodega estéril ni una élite. Ofrecemos el único catálogo en Colombia con miles de títulos curados minuciosamente, creciendo con el aporte de cada lector que se despide de un libro.

Polo cultural

  • El libro como objeto de valor
  • Lo clásico, lo que resiste el tiempo
  • La biblioteca como templo
  • La palabra "incunabula" (erudita)

03 — Sistema Tipográfico

Las Letras

Playfair Display + Inter. Playfair proviene de la tradición tipográfica del siglo XVIII (Caslon, Baskerville). Inter fue diseñada para pantallas de alta resolución. El par Serif/Sans crea jerarquía sin fatiga visual.

Tipografía Primaria — Playfair Display (Serif) Uso: Encabezados principales, títulos de libros, citas del manifiesto. Aporta el carácter editorial clásico.

El Logo

El vendedor ambulante de libros del Renacimiento. Figura histórica que conecta el concepto de los incunables con el acto de hacer circular el conocimiento. El logo en proceso de vectorización SVG.
