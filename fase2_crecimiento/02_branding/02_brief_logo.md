# Brief: Rediseño Logo Incunabula
**Fecha:** 28 Sep 2026
**Estatus:** Bonificación (ADR-016)

## Concepto
Mantener el concepto actual: una ilustración de un vendedor ambulante de libros de la época renacentista. La marca Incunabula se basa en el término "incunable" (primeros libros impresos).

## Requisitos y Alcance (Confirmado con el Cliente)
- **Versiones (2):**
  1. Versión Horizontal (Ilustración + Tipografía)
  2. Versión Isotipo (Solo Ilustración, para avatares y favicons)
- **Rondas de modificaciones:** Máximo dos (2) rondas de revisión.
- **Formato:** Vectorial puro (SVG) para la web, con fondos transparentes, y versiones de alto contraste (blanco sobre negro y viceversa).
- **Estilo:** "Editorial accesible". Que luzca como el sello de una imprenta antigua, pero lo suficientemente limpio para pantallas móviles. No debe parecer excesivamente lujoso/inalcanzable (para no ahuyentar al público de usados baratos).

## Uso Principal
- Cabecera web (Desktop/Móvil).
- Correos electrónicos transaccionales (YayMail).
- Favicon y avatar de redes (Instagram: 83.4k).
- Merchandise (Tote bag de alta venta).
