## Contexto y Punto de Partida

> [!IMPORTANT]
> Incunabula **ya tiene una identidad base** (logo, concepto "primeras imprentas", paleta preliminar). El trabajo no es partir de cero, sino auditar lo que existe, decidir qué se conserva, qué se mejora y qué se crea desde cero. Todo lo que no existe (que es la mayoría) debe ser creado.

**Lo que existe:**
- Logo: Ilustración de vendedor de libros del Renacimiento + tipografía antigua
- Concepto narrativo: "Primeras imprentas" / Incunables
- Paleta preliminar (no oficial): Tinta (#111111), Pergamino (#F5F3EE), Carmesí (#B22222)
- Tipografías propuestas: Playfair Display (headings) + Inter (body)
- Tono deseado: "Minimalista pero cercano. Que dé confianza"
- Diferenciador clave: Catálogo inmenso que crece diariamente, precios más bajos.
- Visión (3 años): Tienda online escalada, más un punto físico y diversificación de productos.
- Referentes visuales: taschen.com/es/ y villegaseditores.com (Recyclivre es solo un referente funcional/UX).

**Lo que NO existe:**
- Manual de marca formal
- Archivos fuente vectoriales del logo (AI/SVG)
- Variaciones del logo (horizontal, vertical, favicon, monocromático)
- Guía de uso del logo (tamaños mínimos, zonas de respeto)
- Paleta de colores oficializada y documentada
- Sistema tipográfico con jerarquías definidas
- Tono de voz y guía de copywriting
- Biblioteca de iconografía / elementos gráficos
- Plantillas de redes sociales estandarizadas
- Sistema de diseño digital (tokens en Elementor)

## FASE 2: Estrategia de Marca
*Objetivo: Definir quién es Incunabula, para quién, y cómo quiere ser percibida.*

### 2.1 Definición de Marca (Brand Foundation)
- [x] **Misión:** Acercar libros de calidad y primeras impresiones (incunables) a lectores apasionados, asegurando una rotación constante de inventario a precios justos.
- [x] **Visión:** En 3 años, expandir el dominio online, abrir un espacio físico con personal dedicado y diversificar las líneas de producto.
- [x] **Valores de marca:** Diversidad de catálogo (siempre hay algo nuevo), accesibilidad (precios bajos), confianza y cultura.
- [x] **Propuesta de valor única (USP):** Un catálogo profundo de libros usados y de colección que se renueva diariamente con opciones asequibles.

### 2.2 Público Objetivo (Buyer Persona)
- [x] **Persona 1 — El Bibliófilo:** Coleccionistas y apasionados de los libros que disfrutan descubriendo nuevas adiciones a su biblioteca. Buscan variedad y buen precio. Tienen dudas al comprar por primera vez debido al tamaño de la tienda.
- [x] **Persona 2 — Cliente aspiracional:** Lectores ocasionales o compradores de regalos. Aún no son el foco principal, el foco es el lector asiduo.
- [x] Validar con datos reales: Geografía (Bogotá #1), rango de edad, dispositivo (55% desktop / 44% mobile). Demandan un sistema de reseñas para validar confianza.

### 2.3 Posicionamiento
- [ ] **Mapa de posicionamiento:** ¿Dónde se ubica Incunabula frente a competidores? (Ej: Buscalibre, Librería Nacional, Panamericana, LibreriasEnColombia)
  - Eje X: Precio (económico ↔ premium)
  - Eje Y: Experiencia (genérica ↔ especializada/curada)
- [ ] **Declaración de posicionamiento:** "Para [persona], Incunabula es [categoría] que [beneficio diferencial] porque [razón]"

### 2.4 Personalidad y Tono de Voz
- [ ] Definir 3-5 adjetivos que describan la personalidad de la marca (ej: culta pero accesible, cálida, curiosa, confiable)
- [ ] **Espectro de tono:** 
  - Formal ←→ Informal: ¿Dónde?
  - Serio ←→ Divertido: ¿Dónde?
  - Técnico ←→ Simple: ¿Dónde?
  - Distante ←→ Cercano: ¿Dónde?
- [ ] **Guía de lenguaje:**
  - Palabras que SÍ usamos (ej: "descubre", "clásico", "tesoro", "hallazgo")
  - Palabras que NO usamos (ej: "barato", "ofertón", "corre que se acaba")
  - ¿Tuteamos o usamos "usted"?
  - ¿Usamos emojis? ¿Cuáles sí y cuáles no?

### 2.5 Análisis de Referentes
- [x] **Referentes Visuales Principales:** 
  - [Taschen](https://www.taschen.com/es/): Diseño editorial, limpio, fotografías impecables de portadas sobre fondos limpios o curados.
  - [Villegas Editores](https://villegaseditores.com/): Elegancia clásica, mucha respiración (whitespace).
- [x] **Referente Funcional:** recyclivre.com (para inspiración de usabilidad y filtros, NO visual).
- [ ] Crear un moodboard con capturas de los elementos que inspiran de Taschen y Villegas (colores, layouts, tipografías, fotografía).

## FASE 3: Identidad Visual
*Objetivo: Crear todos los elementos gráficos que conforman la marca.*

### 3.1 Logo
- [x] **Decisión crítica:** Refinar/Rediseñar el concepto actual con calidad profesional. 
  - El logo actual (vendedor de la Edad Media) gusta por su vínculo conceptual, pero es percibido como plano y poco profesional.
  - **DATO CRÍTICO:** Cambiar el logo radicalmente (ej: a una simple "I") causó confusión en los clientes y pérdida de reconocimiento en Instagram. **Se debe mantener el concepto figurativo o evolucionarlo muy cuidadosamente.**
- [ ] Rediseñar o Vectorizar el logo en formato SVG/AI (indispensable para escalabilidad).
- [ ] Crear variaciones obligatorias:
  - [ ] **Logo principal** (horizontal con texto)
  - [ ] **Logo compacto** (isotipo solo, sin texto — para favicon, avatares de redes)
  - [ ] **Logo monocromático** (blanco sobre oscuro / negro sobre claro)
  - [ ] **Logo con tagline** (si se define un tagline)
- [ ] Definir **zona de respeto** (espacio mínimo alrededor del logo)
- [ ] Definir **tamaño mínimo** de reproducción (px para digital, cm para impreso)
- [ ] Documentar usos incorrectos del logo (estirar, rotar, cambiar colores sin autorización)

### 3.2 Paleta de Colores
- [ ] **Definir paleta primaria** (2-3 colores principales):
  - Color Principal (dominante en headers, botones CTA)
  - Color Secundario (complemento para fondos, secciones alternas)
  - Color de Acento (para badges de oferta, alertas, enlaces activos)
- [ ] **Definir paleta neutra** (fondos, textos, bordes):
  - Fondo claro principal
  - Fondo claro secundario (para alternar secciones)
  - Texto principal
  - Texto secundario (subtítulos, descripciones)
  - Bordes y separadores
- [ ] **Definir paleta funcional** (estados del sistema):
  - Éxito (verde para "En stock", "Pedido confirmado")
  - Advertencia (amarillo/naranja para "Pocas unidades")
  - Error (rojo para "Agotado", errores de formulario)
  - Info (azul para notificaciones neutras)
- [ ] Documentar cada color con: nombre, código HEX, RGB, y ejemplo de uso
- [ ] Verificar contraste WCAG AA (texto sobre fondo) para accesibilidad

### 3.3 Tipografía
- [ ] **Tipografía primaria (Headings H1-H6):**
  - Familia tipográfica (ej: Playfair Display)
  - Pesos a usar (Regular, Bold, etc.)
  - Tamaños por nivel (H1: 36px, H2: 28px, H3: 22px...)
- [ ] **Tipografía secundaria (Body, UI, navegación):**
  - Familia tipográfica (ej: Inter)
  - Pesos a usar
  - Tamaño base del body text (recomendado: 16px)
  - Interlineado (line-height)
- [ ] **Tipografía de acento (opcional):**
  - Para elementos especiales (precios, badges, CTAs destacados)
- [ ] Verificar que las fuentes estén disponibles en Google Fonts (carga gratuita y rápida)
- [ ] Definir la escala tipográfica completa (desde caption 12px hasta display 48px+)

### 3.4 Iconografía y Elementos Gráficos
- [ ] Definir estilo de iconos (outlined, filled, duotone)
- [ ] Seleccionar una biblioteca de iconos consistente (ej: Lucide, Phosphor, Heroicons)
- [ ] Definir si se usarán ilustraciones adicionales al estilo del logo (renacentista/editorial)
- [ ] Definir estilo de separadores, ornamentos o viñetas decorativas (si aplica al concepto editorial)

### 3.5 Fotografía y Estilo Visual
- [ ] Definir el estilo fotográfico de los productos:
  - ¿Fondo blanco limpio? ¿Fondo con textura (madera, tela)?
  - ¿Fotos flat lay? ¿Con elementos decorativos (lentes, café, marcapáginas)?
- [ ] Definir si se usan fotos de personas/lifestyle
- [ ] Crear lineamientos para fotos de redes sociales
