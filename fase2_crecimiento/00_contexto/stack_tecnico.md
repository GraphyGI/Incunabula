## ANÁLISIS DE RIESGOS Y ALERTAS

### 🔴 CRÍTICO — WooCommerce 10.8.1 → 11.0.0 (versión mayor)
WooCommerce 11.0.0 es un **salto de versión mayor**. Las versiones mayores pueden contener cambios que rompan la compatibilidad con:
- Tema Bookory (no certificado para esta versión)
- Plugins de pago (Wompi, Addi)
- Plugins de importación (WP All Import Pro suite)
- Plugins de carrito y checkout

**Acción OBLIGATORIA:** Nunca actualizar directamente en producción. Secuencia correcta:
1. Clonar sitio en staging (hPanel → Staging)
2. Actualizar WooCommerce 11.0.0 en staging
3. Probar checkout completo con Wompi
4. Probar imports con WP All Import
5. Si todo funciona → actualizar en producción con backup previo

### 🔴 URGENTE — Cart Abandonment Recovery (2 alertas activas)
1. Database update required → Backup + Update Database
2. Legacy UI deprecation → Switch to New UI

### ⚠️ PERFORMANCE — Ultimate Addons para Elementor (UAE)
UAE carga +60 widgets adicionales de Elementor aunque no todos se usen. Combinado con Elementor Pro + Bookory, esto aumenta el JS/CSS bloat.
Verificar en LiteSpeed Cache que los assets de UAE estén siendo cacheados y minificados.
**⚠️ DECISIÓN PENDIENTE:** Antes del rediseño con Elementor, definir si UAE se queda o se elimina. Si se diseña con sus widgets y luego se elimina, el diseño se rompe.

### ⚠️ VERIFICAR — Advanced Custom Fields (ACF)
En el proyecto de rescate, ACF Pro pirata fue eliminado. Ahora aparece "Advanced Custom Fields 6.8.4". Debe confirmarse:
- ¿Es la versión gratuita o la Pro?
- ¿Tiene licencia legítima?
- ¿Se instaló para trabajar con WP All Import Pro?

### ⚠️ POSIBLE DUPLICADO — WP All Import ACF Add-On (Free + Pro)
Aparecen ambas versiones (free y pro) instaladas. Verificar cuál está activa y si la free puede eliminarse.
